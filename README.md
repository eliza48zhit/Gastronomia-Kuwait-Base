🛠️ Especificaciones Técnicas del ADN Kuwaití
El contrato mantiene la arquitectura de alto rendimiento con validaciones de rango específicas para la región:

Intensidad de Infusión Ghee (uint256): Mide el nivel de saturación de especias (azafrán, cardamomo, loomi) en la grasa. Un 85 en el Mutabbaq Samak indica una aromatización profunda antes de entrar en contacto con el grano.

Minutos de Sellado de Proteína (uint256): Registra el tiempo de exposición al fuego directo para generar la reacción de Maillard. Validado hasta 60 minutos.

Utiliza Arroz Basmati (bool): Validador que diferencia entre las técnicas de grano largo importado y las matrices de trigo integral como el Jareesh.

Gobernanza Restringida: Implementación de hasVoted para asegurar que cada wallet en Base aporte un único voto al consenso de calidad.
